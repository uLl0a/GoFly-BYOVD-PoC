# GoFlyDrv BYOVD PoC

Esta herramienta es una Prueba de Concepto (PoC) diseñada para demostrar la interacción con controladores de kernel (*kernel-mode drivers*) vulnerables mediante la técnica **BYOVD** (Bring Your Own Vulnerable Driver), utilizando IOCTL para interactuar con el espacio del núcleo (*Ring 0*).
